# GitHub Commands

Run these exact commands in your terminal inside the `studybuddy` folder to push this project to GitHub.

Make sure you replace `YOUR_REPOSITORY_URL` with the actual URL of your newly created GitHub repository (e.g., `https://github.com/username/studybuddy.git`).

```bash
git init
git add .
git commit -m "Initial commit: Add StudyBuddy MVP"
git branch -M main
git remote add origin YOUR_REPOSITORY_URL
git push -u origin main
```
